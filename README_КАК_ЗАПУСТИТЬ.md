# 🎮 Математическая Магия

Добро пожаловать в игру "Математическая Магия"!

## 📦 Установка и запуск (ОЧЕНЬ ПРОСТО!)

### Для Windows:

1. **Распакуйте архив** в любую папку (например, на Рабочий стол)

2. **Проверьте, установлен ли Python:**
   - Откройте командную строку (Win + R → введите `cmd` → Enter)
   - Введите: `python --version`
   - Если увидели версию Python (например, `Python 3.12.10`) — всё готово!
   - Если ошибка — установите Python (см. ниже)

3. **Запустите игру:**
   - Откройте папку с игрой
   - **Дважды кликните** на файл `ЗАПУСТИТЬ_ИГРУ.bat`
   - Всё! Игра запустится автоматически!

---

### Если Python не установлен:

1. Перейдите на сайт: https://www.python.org/downloads/
2. Скачайте последнюю версию Python для Windows
3. **ВАЖНО:** При установке поставьте галочку ✅ **"Add Python to PATH"**
4. Нажмите "Install Now"
5. После установки снова запустите `ЗАПУСТИТЬ_ИГРУ.bat`

## ❓ Проблемы?

### Игра не запускается:
- Убедитесь, что Python установлен и добавлен в PATH
- Попробуйте переустановить Python с официального сайта
- Убедитесь, что все файлы из архива распакованы в одну папку

### Ошибка с tkinter:
- Библиотека tkinter обычно идёт вместе с Python
- При установке Python убедитесь, что выбран компонент "tcl/tk and IDLE"
